6. Conditionals: which type do I need?

All five conditional types with examples from this unit.

TypeWhen to use itFormExample
Zerogeneral truths, rules, things that are always true
общие истины, правила		if + present simple, present simpleIf you don't acknowledge your sources, it counts as plagiarism.
Firstreal or likely situations in the future
реальное будущее		if + present simple, will / can / imperativeIf you hand in your first draft early, your tutor will give you feedback.
Secondunreal or unlikely present or future; advice
нереальное настоящее или будущее, совет		if + past simple (were for all persons), would + infinitiveIf I were you, I would make a mind map.
If I had more time, I would carry out more research.
Thirdunreal past: regret, criticism
нереальное прошлое, сожаление		if + past perfect, would have + past participleIf I had started my essay earlier, I would have got a much better grade.
Mixed Aa past condition has a result in the present
прошлое условие → результат сейчас		if + past perfect, would + infinitiveIf I had done some revision every week, I wouldn't be so exhausted now.
Mixed Ba present or permanent state has a result in the past
состояние сейчас → результат в прошлом		if + past simple, would have + past participleIf I weren't so disorganised, I would have submitted it on time.
How to choose.
  • A rule or a fact that is always true? → zero.
  • A real possibility in the future? → first.
  • Imagining the present or the future as different from reality, or giving advice? → second.
  • Imagining the past as different, with a result in the past? → third.
  • The two times are different? Past condition + present result → mixed A. Present state + past result → mixed B.
Watch out.
  • Would goes only in the main clause, never in the if-clause. ✗ If I would have revised… ✓ If I had revised… По-русски «бы» стоит в обеих частях, по-английски нет.
  • Put a comma after the if-clause when it comes first: If I had started earlier, I would have passed. No comma when it comes second: I would have passed if I had started earlier.
  • Were is used for all persons in the if-clause of the second and mixed B types: If I were… / If she were…
  • Could or might can replace would: If I had revised, I might feel more confident now.
